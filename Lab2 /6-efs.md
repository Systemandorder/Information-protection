

## Шифрування файлів (EFS)

> Потребує **Pro/Enterprise**. У Home EFS недоступна взагалі.

### Терміни

**EFS (Encrypting File System)** шифрування вмісту файлів на рівні NTFS. Кожен файл шифрується випадковим симетричним ключем (FEK), а сам FEK шифрується відкритим ключем користувача з його EFS-сертифіката. Прочитати файл може лише власник відповідного закритого ключа — **навіть якщо NTFS-дозволи дозволяють доступ**.

Це ключова відмінність від звичайних ACL: ACL контролює дозвіл, EFS контролює фізичну можливість розшифрувати. Дозвіл без ключа — марний.

### Налаштування 🔴

```cmd
net user <USER> <PASS> /add
net user <USER2> <PASS> /add
:: тимчасові користувачі для демонстрації, видалити після роботи
```

Від імені `<USER>`:

```
mkdir C:\EFSTest
C:\EFSTest → Свойства → Другие → Шифровать содержимое для защиты данных
:: вмикає EFS для папки; файли всередині (secret.txt) шифруються автоматично

secret.txt → Свойства → Другие → Подробно
:: список користувачів, яким файл доступний — спочатку лише <USER>

certmgr.msc → Личное → Сертификаты
:: сертифікат <USER> з призначенням "Шифрующая файловая система"
```

Від імені `<USER2>` (має NTFS-дозвіл на папку, але не має EFS-ключа):

```cmd
type C:\EFSTest\secret.txt
:: "Отказано в доступе" — NTFS-дозвіл є, EFS-ключа немає

echo test> %USERPROFILE%\mine.txt
cipher /e %USERPROFILE%\mine.txt
:: шифрування власного файлу заразом створює особистий EFS-сертифікат <USER2>
```

Надання доступу (від `<USER>`):

```
secret.txt → Подробно → Добавить → сертифікат <USER2>
```

Після цього `type C:\EFSTest\secret.txt` під `<USER2>` вже працює.

**Важливо:** додавати користувачів до EFS-доступу можна лише **на рівні файлу**, не папки — якщо файлів багато, додавати треба кожен окремо (або через `cipher /adduser` скриптом).

**Висновок.** EFS — другий, незалежний від ACL шар захисту: навіть адміністратор або власник папки без потрібного сертифіката не прочитає вміст зашифрованого файлу (крім Data Recovery Agent, якщо він налаштований).

### Прибрати за собою 🔴

```cmd
rmdir /s /q C:\EFSTest
net user <USER> /delete
net user <USER2> /delete
```
