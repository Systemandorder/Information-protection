

## Політика паролів, блокування, прав і Security Options

> Весь цей файл потребує `secpol.msc`, тобто **Windows Pro/Enterprise**. У Home виконай на хост-системі (якщо вона Pro) — див. README.

### Політика паролів і блокування 🟢

```
secpol.msc
Account Policies → Password Policy
Account Policies → Account Lockout Policy
```

**Password Policy** — вимоги до пароля: історія (скільки старих паролів пам'ятає система), максимальний і мінімальний термін дії, мінімальна довжина, складність, зворотне шифрування (має бути вимкнене — зберігати паролі зворотно-шифрованими небезпечно).

**Account Lockout Policy** — захист від підбору: поріг невдалих спроб входу, тривалість блокування, час до скидання лічильника спроб.

| Параметр | Типово слабко | Рекомендовано політикою |
|---|---|---|
| Мінімальна довжина пароля | 0 (немає вимоги) | ≥ 8 символів |
| Складність пароля | вимкнена | увімкнена |
| Максимальний термін дії | 42 дні | 42 дні (ок) |
| Мінімальний термін дії | 0 | ≥ 1 день (щоб не обходити історію швидкою зміною туди-назад) |
| Історія паролів | 0 | 5 останніх |
| Поріг блокування | 10 спроб | 5 спроб |
| Тривалість блокування | 10 хв | 15 хв |

### Права (привілеї) користувача 🟢

```
secpol.msc
Local Policies → User Rights Assignment
```

**Право (привілей)** — прив'язане до **користувача**, дозволяє системну дію (вимкнути комп'ютер, завантажити драйвер, налагодити будь-який процес), незалежно від ACL конкретних об'єктів. Відрізняється від **дозволу (permission)**, який прив'язаний до **об'єкта** (файл, папка) — див. `4-ntfs-acl.md`.

| Право | Кому типово видано | Що дозволяє |
|---|---|---|
| Архивация файлов и каталогов | Адміністратори, Операторы архива | читати файли для резервного копіювання в обхід ACL |
| Отладка программ | Адміністратори | підключатися налагоджувачем до будь-якого процесу |
| Загрузка и выгрузка драйверов устройств | Адміністратори | встановлювати драйвери |
| Смена владельцев файлов или других объектов | Адміністратори | ставати власником будь-якого об'єкта |
| Управление аудитом и журналом безопасности | Адміністратори | налаштовувати аудит, читати журнал безпеки |
| Локальный вход в систему | Адміністратори, Пользователи | входити за консоллю |
| Запретить локальный вход | Гость | явна заборона входу (перекриває дозвіл) |

Привілеї й дозволи можуть перетинатися: право «Архивация файлов» дозволяє прочитати файл, на який немає ACL-дозволу — привілей сильніший за ACL.

### Security Options (загальні перемикачі) 🟢

```
secpol.msc
Local Policies → Security Options
```

Набір перемикачів поведінки системи: UAC, мережевий доступ, шифрування, інтерактивний вхід. Значення «Не определено» означає, що діє поведінка за замовчуванням.

| Параметр | Приклад значення | Що означає |
|---|---|---|
| Контроль учётных записей: все администраторы работают в режиме одобрения | Включён | адміністратор працює зі звуженим маркером (UAC) |
| Контроль учётных записей: запрос на повышение для администраторов | Запрос согласия | показується вікно «Так/Ні» |
| Контроль учётных записей: запрос на повышение для обычных пользователей | Запрос учётных данных | потрібен пароль адміністратора |
| Сетевая безопасность: не хранить хэш LAN Manager | Включён | слабкий старий хеш пароля не зберігається |
| Сетевой доступ: запретить анонимный доступ к именованным каналам | Включён | без логіна й пароля по мережі не підключитися |
| Интерактивный вход: напоминать об истечении срока пароля | 5 дн. | попередження за N днів |

**Висновок.** Ці три оснастки разом формують політику безпеки станції: що саме вимагається від пароля, хто що може робити системно (привілеї) і як поводиться сама система (Security Options). Усе це — налаштування, а не одноразові дії: зміни зберігаються до наступної зміни.
