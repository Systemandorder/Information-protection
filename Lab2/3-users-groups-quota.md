

## Створення користувачів, адміністратора, груп, квота диска

> У Home немає `lusrmgr.msc` — усе робиться командним рядком, і це навіть зручніше для звіту (є текстовий вивід для підтвердження).

### Створення користувачів і адміністратора 🔴

```cmd
net user <USER> <PASS> /add
net user <USER2> <PASS> /add
net user <USER3> <PASS> /add
net user <ADMIN> <PASS> /add
:: створює локальний обліковий запис із заданим паролем

net localgroup Администраторы <ADMIN> /add
:: додає <ADMIN> до вбудованої групи адміністраторів — тепер він привілейований

net user
net user <USER>
net localgroup Администраторы
:: перевірка: список облікових записів, параметри конкретного, склад групи адміністраторів
```

Пароль має відповідати політиці складності з `2-policy-secpol.md`, інакше `net user ... /add` поверне помилку.

### Квота диска 🟡

```
Диск C: → Свойства → вкладка Квота → Показать параметры квот
Включить управление квотами → Записи квот → Квота → Создать запись квоты → <USER>
Ограничить использование диска до <N> МБ, порог предупреждения <N-5> МБ
```

Квота обмежує обсяг диска, який можуть займати файли, власником яких є конкретний користувач. Працює лише на NTFS. Корисно порівняти з ACL: квота рахує обсяг **по власнику файлу**, а не по тому, хто фізично створив файл у спільній папці.

### Групи користувачів 🔴

```cmd
net localgroup <GROUP> /add
net localgroup <GROUP2> /add
net localgroup <GROUP3> /add
:: створює локальну групу

net localgroup <GROUP> <USER> /add
net localgroup <GROUP2> <USER2> /add
net localgroup <GROUP3> <USER3> /add
:: додає користувача до групи

net localgroup
net localgroup <GROUP>
:: перевірка: список усіх груп, склад конкретної
```

Для цієї методички зручно тримати схему «один користувач — одна основна група» (`<USER>` → `<GROUP>`, `<USER2>` → `<GROUP2>`, `<USER3>` → `<GROUP3>`) — саме вона використовується далі в `4-ntfs-acl.md` для побудови прав через групи.

**Висновок.** `net user`/`net localgroup` — повний функціональний еквівалент `lusrmgr.msc` для базових операцій: створення, видалення, членство. Графічна оснастка зручніша для перегляду, командний рядок — для відтворюваних, задокументованих дій (саме тому для звіту краще командний рядок: є текстовий вивід).

### Прибрати за собою 🔴

```cmd
net user <USER> /delete
net user <USER2> /delete
net user <USER3> /delete
net user <ADMIN> /delete
net localgroup <GROUP> /delete
net localgroup <GROUP2> /delete
net localgroup <GROUP3> /delete
```
