

## Механізми захисту ОС Windows 

Узагальнена методичка за мотивами практичної роботи «Механізми захисту ОС Windows» (маркер доступу, SID, ACL, UAC, аудит, EFS). Орієнтована на будь-яку редакцію Windows 10/11, а не на одну конкретну машину.

Про заготовки (`<USER>` тощо) і позначки 🟢🟡🔴 дивись нижче.

### Яка редакція Windows тобі потрібна

| Потрібно | Home | Pro / Enterprise |
|---|---|---|
| `whoami`, `net user`, `net localgroup`, Process Explorer, `icacls`, `auditpol`, Event Viewer | ✅ | ✅ |
| `secpol.msc` (політика паролів, блокування, User Rights Assignment, Security Options) | ❌ | ✅ |
| `lusrmgr.msc` (графічне керування користувачами й групами) | ❌ | ✅ |
| EFS (шифрування файлів, `cipher /e`) | ❌ | ✅ |

**Щоб не застрягти:**

1. Став віртуалку саме з **Windows 10/11 Pro** — тоді все виконується в одному місці без костилів.
2. Якщо ВМ уже Home — пункти з `secpol.msc`/EFS виконай на **хост-системі**, якщо вона Pro, або онови ВМ: `DISM /Online /Set-Edition` (без ключа працює кілька днів в оцінювальному режимі).
3. Якщо Pro ніде немає — замінюй `secpol.msc`-пункти командами `auditpol`, `net accounts`, `wmic useraccount` і чесно познач у звіті, що оснастка була недоступна.

**Знімок ВМ перед 🔴-командами:**

```bash
VBoxManage snapshot "<VM_NAME>" take "before-lab" --description "чистий стан перед лабою"
VBoxManage snapshot "<VM_NAME>" restore "before-lab"
```

### Заготовки

| Заготовка | Що підставити | Приклад |
|---|---|---|
| `<USER>`, `<USER2>`, `<USER3>` | ім'я користувача | `user1` |
| `<ADMIN>` | ім'я привілейованого користувача | `admin2` |
| `<GROUP>`, `<GROUP2>`, `<GROUP3>` | ім'я локальної групи | `group1` |
| `<PASS>` | пароль (відповідно до політики складності) | `Lab_Pass1!` |
| `<FOLDER>`, `<FOLDER2>`, `<FOLDER3>` | шлях до папки | `C:\Lab\Folder1` |
| `<FILE>` | шлях до файлу | `C:\Lab\Folder1\doc1.txt` |
| `<SID>` | SID користувача/групи (з `whoami /all`) | `S-1-5-21-...-1000` |
| `<PID>` | номер процесу (з Process Explorer / `tasklist`) | `4321` |
| `<GUID>` | GUID підкатегорії аудиту | `{0CCE921D-69AE-11D9-BED3-505054503030}` |
| `<VM_NAME>` | назва віртуальної машини | `Win10-Lab` |
