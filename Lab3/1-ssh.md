# Частина 1. SSH 

Клієнт `<CLIENT_IP>` (наприклад Kali), сервер `<SERVER_IP>` (наприклад Ubuntu), обидві VM в одній мережі Host-only.

## 1.1 Мережа 🟡

```bash
ip a
# ip a показує мережні інтерфейси та їхні IP адреси
# потрібно на обох машинах, щоб знати IP одна одної

ping -c 4 <SERVER_IP>
# ping перевіряє досяжність іншої машини
# -c 4 обмежує перевірку чотирма пакетами замість нескінченного потоку
```

Якщо на одній з машин IP ще не задано вручну

```bash
sudo ip addr add <IP>/24 dev <IFACE>
sudo ip link set <IFACE> up
# ip addr add призначає інтерфейсу адресу
# ip link set up вмикає інтерфейс, якщо він був вимкнений
# ці адреси тимчасові, зникають після перезавантаження VM
```

## 1.2 SSH сервер 🔴

```bash
sudo apt install openssh-server -y
sudo systemctl start ssh
# apt install openssh-server встановлює службу SSH сервера
# systemctl start ssh запускає цю службу
# зміна системна, встановлений пакет і запущена служба лишаються після виходу

ps -A | grep ssh
# ps -A виводить усі процеси
# grep ssh лишає лише ті, де є слово ssh, має бути видно sshd
```

## 1.3 Підключення 🟢

```bash
ssh -l <USER> <SERVER_IP>
# ssh -l USER HOST відкриває захищену сесію під іменем USER на машині HOST
# при першому підключенні треба підтвердити відбиток ключа сервера (yes)

whoami
exit
# whoami показує ім'я поточного користувача всередині сесії
# exit закриває сесію і повертає в оболонку клієнта
```

## 1.4 Команди та інтерактивні програми 🟢

```bash
ssh -l <USER> <SERVER_IP> "date; uptime"
# виконує обидві команди на сервері без входу в інтерактивну сесію
# date показує поточний час сервера, uptime час роботи й завантаження

ssh -t -l <USER> <SERVER_IP> vi
# -t виділяє псевдотермінал, потрібно для повноекранних програм
# запускає редактор vi на сервері, вихід командою :q
```

## 1.5 Копіювання файлів 🟡

```bash
echo test > file.txt
scp file.txt <USER>@<SERVER_IP>:
# scp копіює файл через захищений канал SSH
# двокрапка в кінці без шляху означає домашню папку користувача на сервері
```

## Прибрати

Нічого стирати не треба, якщо `openssh-server` потрібен і для інших лаб. Якщо ні

```bash
sudo systemctl stop ssh
sudo apt remove openssh-server
```
