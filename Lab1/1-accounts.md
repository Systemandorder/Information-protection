# 1. Облікові записи, групи, паролі (розділ 2 методички)

Про заготовки (`<USER>` тощо) і позначки 🟢🟡🔴 дивитися [README](README.md).

## Три файли, в яких усе зберігається

| Файл | Що там | Хто читає |
|---|---|---|
| `/etc/passwd` | список користувачів | усі |
| `/etc/shadow` | **хеші паролів** і терміни їх дії | лише root |
| `/etc/group` | список груп і їхніх учасників | усі |

**Хеш** це відбиток пароля. Сам пароль не зберігається. Система хешує те, що ти ввів, і порівнює з відбитком. З відбитка пароль зворотно не відновити, його лише підбирають перебором (John the Ripper нижче).

### Поля `/etc/passwd` (розділювач `:`)

```
anna:x:1001:1001:Anna K.:/home/anna:/bin/bash
 1   2  3    4      5        6          7
```

1. ім'я; 2. `x` = хеш у `/etc/shadow`; 3. UID; 4. GID основної групи; 5. коментар; 6. домашній каталог; 7. оболонка входу (`/usr/sbin/nologin` або `/bin/false` = вхід заборонено).

### Поля `/etc/shadow`

```
anna:$y$j9T$...хеш...:20734:0:99999:7:::
 1         2             3   4   5   6 7 8 9
```

1. ім'я; 2. хеш (`*`/`!` = заблоковано; порожнє = **пароля немає**); 3. дата останньої зміни (дні від 01.01.1970); 4. мін. днів між змінами; 5. макс. термін дії; 6. попередження (днів); 7. неактивність; 8. дата відключення; 9. резерв.

### Поля `/etc/group`

```
team:x:1002:anna,bob
  1  2   3      4
```

1. назва; 2. `x`; 3. GID; 4. учасники через кому (користувачі з цією групою як основною тут можуть бути не вказані).

## 2.1 Аналіз підсистеми автентифікації

### 2.1.1 Які є облікові записи 🟢

```bash
cut -d: -f1 /etc/passwd
# cut     — вирізає колонку з тексту
# -d:     — розділювач полів ":" (бо саме так розділений /etc/passwd)
# -f1     — взяти лише ПЕРШЕ поле = ім'я користувача
```

### 2.1.2 Хто зараз увійшов 🟢

```bash
who
# who   — коротко: хто увійшов, термінал, час входу

w
# w     — те саме що who, + що кожен користувач зараз робить (яка команда виконується)

last -n 10
# last    — історія входів (з журналу /var/log/wtmp)
# -n 10   — показати лише останні 10 записів
```

### 2.1.3 Локально чи віддалено 🟢

```bash
who -a
# who -a  — повна інформація про сесії, включно з джерелом входу в дужках у кінці рядка
```
Як читати дужки в кінці рядка:
- `(:0)` або порожньо, термінал `tty1`/`seat0` → вхід **локальний**;
- `(IP-адреса)` або ім'я хоста, термінал `pts/N` → вхід **віддалений** (напр. SSH).

### 2.1.4 Акаунти, створені після встановлення 🟢

```bash
grep -E '^UID_MIN|^UID_MAX' /etc/login.defs
# grep -E            — пошук за розширеним регулярним виразом
# '^UID_MIN|^UID_MAX' — рядки, що ПОЧИНАЮТЬСЯ з UID_MIN або UID_MAX
# /etc/login.defs    — файл, де задані ці межі UID

awk -F: '$3 >= 1000 && $3 != 65534 {print $1, $3}' /etc/passwd
# awk -F:          — розділювач полів ":"
# $3               — третє поле рядка = UID
# >= 1000          — звичайні (не системні) акаунти мають UID від 1000
# && $3 != 65534   — виключити nobody (його UID саме 65534)
# {print $1, $3}   — вивести ім'я та UID
```

### 2.1.5 Групи 🟢

```bash
cut -d: -f1 /etc/group
# cut -d: -f1   — перше поле = назва групи (той самий принцип, що й для passwd)
```

### 2.1.6 Хто в якій групі 🟢

```bash
getent group | awk -F: '$4 != "" {print $1": "$4}'
# getent group     — читає базу груп системи (надійніше за прямий cat /etc/group,
#                    бачить і зовнішні джерела, напр. LDAP)
# awk -F:          — розділювач ":"
# $4 != ""         — лишити тільки групи, у яких список учасників (4-те поле) НЕ порожній
# {print $1": "$4} — вивести "назва_групи: учасники"

for u in $(cut -d: -f1 /etc/passwd); do echo "$u: $(id -Gn "$u")"; done
# for u in $(...)         — перебрати по черзі ВСІХ користувачів із /etc/passwd
# id -Gn "$u"             — вивести НАЗВИ всіх груп (не лише номери) користувача $u,
#                           включно з основною групою (яку попередня команда не показує)
```

### 2.1.7 Хто лише в одній групі 🟢

```bash
for u in $(cut -d: -f1 /etc/passwd); do
  [ "$(id -G "$u" | wc -w)" -eq 1 ] && echo "$u"
done
# for u in $(...)        — перебрати всіх користувачів
# id -G "$u"              — номери (GID) усіх груп користувача, через пробіл
# wc -w                   — порахувати кількість слів (= кількість груп)
# -eq 1                   — умова: рівно ОДНА група
# && echo "$u"             — якщо умова істинна  вивести ім'я
```

### 2.1.8 Хто не може увійти 🟢

```bash
grep -E '(/nologin|/false)$' /etc/passwd | cut -d: -f1
# grep -E              — пошук за розширеним регулярним виразом
# '(/nologin|/false)$' — рядок ЗАКІНЧУЄТЬСЯ на /nologin АБО /false (це 7-ме поле  оболонка)
# | cut -d: -f1        — з відібраних рядків взяти лише ім'я користувача
```

### 2.1.9 Без пароля 🟢

```bash
sudo awk -F: '$2 == "" {print $1}' /etc/shadow
# sudo              — потрібні права root, бо /etc/shadow читає лише він
# $2 == ""          — друге поле (хеш пароля) ПОРОЖНЄ = пароля немає зовсім
# {print $1}        — вивести ім'я такого користувача

sudo awk -F: '$2 == "*" || $2 ~ /^!/ {print $1}' /etc/shadow
# $2 == "*"         — хеш дорівнює "*" = вхід по паролю неможливий (службовий акаунт)
# $2 ~ /^!/         — хеш ПОЧИНАЄТЬСЯ з "!" = акаунт заблоковано
```

### 2.1.10 Хеші (замасковано) 🟢

```bash
sudo awk -F: 'BEGIN{OFS=":"} { if ($2 ~ /^\$/) $2="***MASKED***"; print }' /etc/shadow
# BEGIN{OFS=":"}            — вихідний розділювач теж ":" (щоб формат рядка не зламався)
# if ($2 ~ /^\$/)           — якщо хеш (2-ге поле) починається з символу "$" (реальний хеш)
# $2="***MASKED***"         — замінити його на маску
# print                     — вивести весь (змінений) рядок
```

### 2.1.11 Яка геш-функція 🟢

```bash
sudo cut -d: -f2 /etc/shadow | grep '^\$' | cut -d'$' -f2 | sort | uniq -c
# cut -d: -f2       — взяти лише 2-ге поле (хеш) з кожного рядка shadow
# grep '^\$'        — лишити тільки рядки, що починаються з "$" (реальні хеші, не * чи !)
# cut -d'$' -f2     — розбити тепер за символом "$" і взяти 2-гу частину = код алгоритму
# sort | uniq -c    — порахувати, скільки разів зустрічається кожен алгоритм

grep ENCRYPT_METHOD /etc/login.defs
# grep ENCRYPT_METHOD — знайти рядок конфігурації, який алгоритм система використовує
#                       за замовчуванням для НОВИХ паролів
```
`$1$`=MD5, `$5$`=SHA-256, `$6$`=SHA-512, `$y$`=yescrypt, `$2b$`=bcrypt.

### 2.1.12 John the Ripper 🟡

```bash
sudo apt install john
# apt install john        — встановити програму для перебору паролів

sudo unshadow /etc/passwd /etc/shadow > ~/hashes.txt
# unshadow               — об'єднує passwd + shadow в один файл формату, зрозумілого John
# > ~/hashes.txt         — зберегти результат у домашній каталог

chmod 600 ~/hashes.txt
# chmod 600               — у файлі лежать хеші паролів, закрити читання для інших користувачів

john --format=crypt --wordlist=/usr/share/john/password.lst --rules ~/hashes.txt
# --format=crypt                        — формат хеша: системний crypt (yescrypt/sha512crypt)
# --wordlist=/usr/share/john/password.lst — словник слів для перебору
# --rules                               — додає мутації слів (цифри в кінці, великі літери тощо)

john --show --format=crypt ~/hashes.txt
# --show  — вивести вже підібрані паролі з попереднього запуску
```
Тест: `echo '<USER>:<ПРОСТИЙ_ПАРОЛЬ>' | sudo chpasswd` 🔴 — ставить простий пароль, щоб перевірити, що перебір узагалі працює.
Після — видали `~/hashes.txt` і `~/.john/john.pot`.

Відновлення за маскою:

```bash
john --format=crypt --mask='?l?l?l?d?d' ~/hashes.txt
# --mask='?l?l?l?d?d'   — шаблон пароля: 3 малі літери + 2 цифри
#   ?l = мала літера (26 варіантів), ?u = велика (26), ?d = цифра (10), ?s = спецсимвол (~33)
```
Ітерацій (гірший випадок) = добуток варіантів позицій: 26·26·26·10·10 = 1 757 600.

### 2.1.13 Політика паролів 🟢

```bash
grep -E '^(PASS_|LOGIN_RETRIES|ENCRYPT_METHOD|UMASK)' /etc/login.defs
# пошук рядків, що починаються на PASS_, LOGIN_RETRIES, ENCRYPT_METHOD або UMASK
# — це й є політика: термін дії пароля, кількість спроб входу, алгоритм, права за замовч.

grep -v '^#' /etc/pam.d/common-password
# -v '^#'   — показати ВСІ рядки, КРІМ тих, що починаються з # (прибрати коментарі)

cat /etc/security/pwquality.conf 2>/dev/null
# показати вимоги до складності пароля, якщо встановлено пакет pwquality
# 2>/dev/null — приховати помилку "файл не знайдено", якщо пакета немає

sudo chage -l <USER>
# chage -l   — вивести терміни дії пароля конкретного користувача
```

### *2.1.14 Інші файли з хешами 🟢

`/etc/gshadow`, `/etc/shadow-`, `/etc/passwd-`, `/var/backups/*.bak`, `/etc/security/opasswd`, `~/.john/john.pot`.

```bash
sudo grep -rlE '\$(y|6|5|1|2[aby])\$[^:]+' /etc /var/backups 2>/dev/null
# -r               — шукати рекурсивно по всіх підкаталогах
# -l               — вивести лише ІМЕНА файлів зі збігом (не самі рядки)
# -E '\$(y|6|...)' — шаблон, що виглядає як початок хеша ($y$, $6$, $5$ тощо)
# /etc /var/backups — де шукати
```

## 2.2 Створення/зміна акаунтів 🔴

```bash
sudo groupadd <GROUP>
# groupadd   — створити нову групу (додає рядок у /etc/group)

sudo groupadd <GROUP2>

sudo useradd -m -s /bin/bash <USER>
# useradd -m          — створити користувача + домашній каталог /home/<USER>
# -s /bin/bash        — яка оболонка входу буде в нього

sudo useradd -m -s /bin/bash <USER2>

sudo passwd <USER>
# passwd <USER>  — інтерактивно задати пароль цьому користувачу

sudo passwd <USER2>

sudo usermod -aG <GROUP> <USER>
# usermod -aG <GROUP> — ДОДАТИ користувача до групи
# -a (append)         — ОБОВ'ЯЗКОВО: без неї існуючі групи користувача будуть ЗАМІНЕНІ

sudo usermod -aG <GROUP>,<GROUP2> <USER2>
# через кому можна додати одразу до кількох груп
```

Перевірка:

```bash
grep -E '<USER>|<USER2>' /etc/passwd
# показати рядки обох нових користувачів у /etc/passwd

sudo grep -E '<USER>|<USER2>' /etc/shadow
# те саме в /etc/shadow (хеш у звіті заміни на маску, не публікуй справжній)

grep -E '<GROUP>|<GROUP2>' /etc/group
# перевірити, що в /etc/group у 4-му полі з'явились імена цих користувачів
```

Прибрати:

```bash
sudo userdel -r <USER>
# userdel -r   — видалити користувача + його домашній каталог (-r = remove home)

sudo userdel -r <USER2>
sudo groupdel <GROUP>
# groupdel   — видалити групу

sudo groupdel <GROUP2>
```
