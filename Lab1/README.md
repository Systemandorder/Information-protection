 

## Як читати команди із заготовками

Заготовка пишеться так: `<ЩОСЬ_ВЕЛИКИМИ>`. Дужки `<` `>` теж треба прибрати.

| Заготовка | Що підставити | Приклад |
|---|---|---|
| `<USER>`, `<USER2>` | ім'я користувача | `anna` |
| `<GROUP>`, `<GROUP2>` | ім'я групи | `team` |
| `<FILE>` | шлях до файлу | `~/notes.txt` |
| `<DIR>` | шлях до каталогу | `/tmp/demo` |
| `<LINK>` | ім'я посилання | `~/notes_link` |
| `<PID>` | номер процесу (бери з `ps`) | `4321` |
| `<PORT>` | номер порту | `22` |
| `<HOST>` | адреса або ім'я сайту | `example.com` |
| `<SCRIPT>` | шлях до скрипта | `/usr/local/bin/hello.sh` |

## Рівні ризику

| Позначка | Значення |
|---|---|
| 🟢 | Лише **читає** інформацію. Безпечно. |
| 🟡 | Створює тимчасові файли чи процеси. Безпечно, але потім прибери за собою. |
| 🔴 | **Змінює** користувачів, права, sudo, PAM. Тільки у віртуальній машині зі знімком. |

## Рівні доступу за 5 хвилин

**1. Три категорії.** власник (`u`), група (`g`), решта (`o`).

**2. Три права:**

| Право | Для файлу | Для каталогу |
|---|---|---|
| `r` | читати вміст | бачити список імен |
| `w` | змінювати вміст | створювати,видаляти файли в ньому |
| `x` | запускати як програму | заходити в каталог |

**3. Цифри.** `r`=4, `w`=2, `x`=1. `chmod 640` = власник `rw-`, група `r--`, решта `---`.

**4. `ls -l`:** `-rwxr-x---` → тип, права власника, групи, решти.

**5. Особливі біти:** SUID (права власника файлу), SGID (права групи), sticky (видаляти може лише власник).

**6. root** — UID 0, для нього перевірки прав майже не діють.

**7.** ACL (кілька груп), sudo (конкретна команда від іншого), PAM (охоронець на вході), атрибути `chattr`.
